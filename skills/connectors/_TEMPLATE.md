# connector: <source>

> 使用方式：复制本模板为 `skills/connectors/<source>.md`，逐要素填写；各要素下的「写什么」为填写说明，示例占位（`<…>`）填完可删。六要素缺一不可（FR-12.2 / DESIGN §5.7）。

## 1. 数据清单

**写什么**：该源可拉的资源类型 × CLI 命令模板 × 输出字段说明；必须含分页方式与速率限制注意。

| 资源类型 | CLI 命令模板 | 输出字段 |
|---|---|---|
| <示例：消息> | `<cli> messages list --chat <id> --since <date> --json` | id, chat_id, ts, text |
| <示例：文档> | `<cli> docs get <page_id> --json` | page_id, title, blocks[] |

注意：<示例：分页用 cursor、每分钟限 60 次、token 过期表现与重登命令>

## 2. locator 格式

**写什么**：回源指针的稳定格式——每条蒸馏候选都要能用它指回原位；无稳定 ID 时写明替代约定。

<示例：`im-x:<chat_id>#<msg_id>` / `notion:<page_id>#<block_id>`；无稳定 ID 时：`<source>:<对话名>@<YYYY-MM-DD HH:mm>`（时间戳替代，写明这是约定而非稳定 ID）>

## 3. 摘录抓取

**写什么**：evidence 双件套的原文片段怎么截——从哪个命令的哪个字段取、截多长、怎么与 locator 拼接。

<示例：取消息 text 字段原文逐字摘录，≤500 字符；超出取含结论句的前 500 字符＋「…」。双件套拼为 `locator | 摘录`，evidence 总长 ≤2000 字符（FR-4.1）；回放默认用片段，不依赖源在线>

## 4. 高发区提示

**写什么**：该源里「关于我的结论」长在哪——收割优先扫的位置与对应记忆类型（决策 / 人物 / 偏好 / 模式四象限的去处）。

<示例：IM 私聊 → 人物沟通偏好（domains/people/）；会议记录 → 决策与承诺（domains/work/）；文档批注 → 写作偏好（person/）；代码评审 → 开发模式（domains/coding/）>

## 5. 隐私红线特化

**写什么**：该源在通用纪律（凭证 / 他人隐私 / 敏感内容不入库；git 历史永久留痕）之上的特化条款；团队内容分流去 repo 的判据见 REQUIREMENTS §3.7。

<示例：IM——他人原话一律不收，只收「我」的结论；云文档——团队规范 / 待办留 repo 不入 Hub；位置轨迹 / 照片 / 语音转写中的第三方信息永不入库>

## 6. 烟测命令

**写什么**：验证 CLI 活着的最小命令——新会话 / 新机收割的第一步先跑它，失败即停。

<示例：`<cli> me --json` 返回当前账号 ⇒ 通过；401 ⇒ 先重新登录再收割>
